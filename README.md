# 智光跟进助手

**智光工作室** · 给中小企业销售团队的跟进智能体 Demo（Hackathon / 对外演示用）。

> 帮销售把线索跟进跑顺：提醒回访、建议话术、写回状态——约两周可验收。

## 如何本地打开 Demo

静态 HTML，**无需构建、无需 Node**。

```bash
git clone https://github.com/jiawenyao401/zhiguang-follow-assistant.git
cd zhiguang-follow-assistant
```

任选一种方式打开：

1. **直接双击 / 浏览器打开**  
   - 跟进工作台：`demo/index.html`  
   - 销售一页通：`demo/one-pager.html`

2. **本地静态服务（推荐，避免个别浏览器 file:// 限制）**

```bash
# Python 3
python3 -m http.server 8080 --directory demo

# 或 npx
npx --yes serve demo -p 8080
```

然后访问：

- 跟进 Demo：http://localhost:8080/  
- 一页通：http://localhost:8080/one-pager.html  

也可在 GitHub 上用 Raw / GitHub Pages / 任意静态托管打开同路径文件。

### Demo 可点流程（销售跟进）

1. 默认进入 **销售跟进** 列表（待跟进线索）  
2. 点击某条线索 → 进入 **详情**  
3. 查看智能体 **建议话术**，可「采用草稿」填入回复框  
4. 「标记完成」→ 状态变为已完成，返回列表可见 chip 更新  

演示数据均为虚构，非真实客户。

## 两周验收清单（可写进 SOW）

1. 至少 1 条主路径跑通：新线索 → 提醒 → 建议话术 → 写回状态
