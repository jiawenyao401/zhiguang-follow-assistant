# 智光跟进助手 · 给技术负责人的一页提纲

**对外主体：** 智光工作室（暂无公司主体）  
**定位：** 给中小企业销售团队的跟进智能体——线索、催办、复盘，约两周可验收。  
**演示壳：** `demo/index.html`（默认打开销售跟进：列表 → 详情 → 建议话术 → 标记完成）

---

## 1. 系统边界（做什么 / 不做什么）

| 做 | 不做（首期） |
|----|-------------|
| 线索录入/导入、跟进提醒、话术建议、复盘摘要 | 不替换完整 CRM |
| 对接常见表格/Webhook/企微机器人（按单配置） | 不自建重型中台 |
| 人工可改可驳回的建议，关键动作留痕 | 不无人全自动外呼/群发（合规风险） |

---

## 2. 参考架构（可按客户环境裁剪）

```
渠道（企微/表单/表格）
    → 接入层（Webhook / 轻量 API）
    → 编排与工具（跟进规则、检索、写回）
    → 模型调用（可换国产/海外；密钥客户侧或工作室托管）
    → 工作台（演示壳同构：列表 / 详情 / 建议话术 / 待办）
```

- 数据默认归客户；工作室可复用通用框架与提示词骨架，不含客户业务数据。
- 标准档交付成本目标：人天+模型合计压在约 ¥7,500 内（对应 1.5 万报价、约 50% 毛利）。仅写入技术文档，不放客户一页通。

---

## 3. 两周验收清单（可写进 SOW）

1. 至少 1 条主路径跑通：新线索 → 提醒 → 建议话术 → 写回状态  
2. 工作台可演示：待跟进列表、单条详情、操作留痕  
3. 配置说明 1 页：环境变量、模型、回调地址  
4. 超范围（多系统深度同步、定制报表等）另报价  

---

## 4. 安全与合规底线

- 不训练客户原始对话进公共模型（除非合同另约定）  
- 密钥不进仓库；演示环境用假数据  
- 开源边界（Hackathon / 对外 Demo）：仅开源通用壳与示例配置；客户提示词、数据、私有连接器默认不开源  

---

## 5. 试点档位与交付物对应

| 档位 | 范围 | 开发交付物 |
|------|------|------------|
| 入门 0.8–1 万 | 单场景 | 单通道接入 + 工作台 + 验收清单 |
| 标准 1.5 万 | 1–2 场景 | 可复用模板 + 微调 + 配置说明 |
| 包月 3–5 千 | 值守小改 | 变更通道 + 小需求排队 |
